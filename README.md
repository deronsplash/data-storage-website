# IT 104: The Evolution of Data Storage

Multi-page website by Deron Acquaye for IT 104 at George Mason University. Compares hard disk drives (HDDs) and solid-state drives (SSDs), including performance, benefits, data security, legal and ethical considerations, and future use.

## Run locally

Download these files together and open `index.html` in a browser. No installation is needed.

## Key files

- `index.html`: site entry point
- `intro.html`, `benefits.html`, `security.html`, `ethics.html`, `conclusion.html`: project content
- `researchpaper.pdf`: linked research paper
- `biblio.html`: citations and references
- `storage_ai_image.svg`, `computer.jpg`, `storage_video.mp4`: site media

The source files include separate blog, wiki, and mobile app pages. Check these pages and the research paper for accuracy and attribution before sharing the repository publicly.
